# Meeting Summary

Summarize only information present in the user's notes. Do not invent owners, deadlines, or decisions.

Before writing the summary, read [references/summary-format.md](references/summary-format.md). It defines the required output sections and the placeholder to use when information is missing.

Keep action items concrete and preserve any dates exactly as written by the user.
