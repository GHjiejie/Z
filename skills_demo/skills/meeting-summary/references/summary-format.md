# Meeting summary format

Use this structure:

```markdown
## 会议结论

- <confirmed decision or conclusion>

## 行动项

| 任务 | 负责人 | 截止时间 |
| --- | --- | --- |
| ... | ... | ... |

## 待确认问题

- <unresolved question>
```

Rules:

- Use `未提供` for a missing owner or deadline.
- If a section has no content, write `- 无`.
- Keep the summary brief; omit conversational filler and repeated statements.
