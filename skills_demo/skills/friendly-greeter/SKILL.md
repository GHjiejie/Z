# Friendly Greeter

Write a concise Chinese greeting that:

1. Names the person or group when supplied.
2. Mentions the occasion or team context when supplied.
3. Uses no more than three sentences unless the user requests another length.
4. Sounds warm and natural without exaggerated praise.

Return only the greeting, followed by the demo's required skill-usage note.
