# Project Kickoff

Read [assets/kickoff-template.md](assets/kickoff-template.md), copy its structure, and fill it using only facts supplied by the user.

- Preserve all headings from the template.
- Replace missing information with `待确认`.
- Express deliverables as observable outcomes.
- Keep risks specific to the stated project rather than adding generic risks.
- Return the completed brief in Markdown; do not modify the template asset.
