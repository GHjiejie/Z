# Task Planning

Use this skill for requests that contain multiple dependent steps, uncertain scope, or a concrete delivery target.

1. Restate the intended outcome and identify constraints before acting.
2. Split the work into observable steps with at most one active step at a time.
3. Inspect available state before making a change; do not assume a resource exists.
4. Keep the plan current as evidence changes and record meaningful blockers.
5. Verify the delivered outcome in proportion to its risk before reporting completion.

For a small, obvious request, execute directly instead of creating ceremonial planning overhead.
