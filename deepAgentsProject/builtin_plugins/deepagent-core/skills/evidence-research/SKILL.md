# Evidence Research

Use this skill when an answer depends on documents, repositories, logs, external sources, or competing claims.

1. Prefer primary evidence and the most authoritative available source.
2. Separate observed facts from inference and label uncertainty explicitly.
3. Compare dates, versions, and scope before combining evidence.
4. Preserve traceability by citing the file, artifact, event, or URL supporting each consequential claim.
5. Summarize findings around the user's decision rather than reproducing source material.

If evidence conflicts, report the conflict and explain which source is more reliable and why.
