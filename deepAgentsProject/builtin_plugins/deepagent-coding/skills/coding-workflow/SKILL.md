# Coding Workflow

Work as the single writer for the repository workspace.

1. Read every applicable `AGENTS.md` before editing files in its scope.
2. Inspect the relevant implementation and tests before deciding on a change.
3. Maintain a concise todo list for multi-step work.
4. Make the smallest coherent change that satisfies the request.
5. Re-read the diff and run verification appropriate to the changed surface.
6. If verification fails, diagnose from real output and revise; never invent success.
7. Finish with changed files, verification evidence, limitations, and remaining risk.
