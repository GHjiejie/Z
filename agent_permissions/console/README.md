# Agent Console

用户管理后台 UI，使用 React、TypeScript、Vite、Lucide 图标和原生 CSS，实现[用户管理接口契约](../docs/user-management-api.md)对应的操作。

## 页面

| 页面 | 内容 |
| --- | --- |
| 登录 | 用户名与密码登录、错误反馈、会话失效提示 |
| 首次改密 | 初始密码验证、新密码与确认、改密后重新登录 |
| 用户管理 | 用户总数与账号统计、搜索、角色与状态筛选、排序、分页、新增、编辑、角色分配、重置密码、启用、禁用、删除 |
| 角色与权限 | 查询并展示系统内置角色和各角色允许的操作，不提供接口未支持的角色编辑功能 |
| 个人设置 | 个人资料、当前权限、本人密码修改 |

管理员可以访问管理页面；普通用户仅访问个人设置。前端根据当前权限呈现操作，实际授权仍由后端执行。

## 启动

在本目录运行：

```bash
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173/console/`。Vite 将 `/api`、`/docs` 和 `/openapi.json` 代理到本机 8000 端口的 FastAPI。后端启动和管理员初始化见[运行说明](../docs/running.md)。

生产构建：

```bash
npm run build
```

构建结果在 `dist/`。重新启动 FastAPI 后，可直接访问 `http://127.0.0.1:8000/console/`，无需额外运行前端服务。

## 状态与交互约定

- 会话令牌保存在当前标签页的 `sessionStorage`，页面刷新后重新核验用户。密码仅在表单提交时使用，不写入浏览器持久存储。
- 首次改密会话只显示改密流程。修改密码成功后清除本地会话，引导重新登录。
- 收到 `401` 时清除失效会话并返回登录页；检测到权限变化或窗口重新获得焦点时，重新读取当前身份和权限。
- 已退出会话的延迟响应会被丢弃，不能覆盖新登录用户的信息或清除新会话。
- 列表请求使用取消信号，避免快速搜索或切换筛选时，旧响应覆盖最新查询结果。
- 编辑、角色、状态、删除、重置密码之前读取目标详情和最新 `ETag`，提交时携带 `If-Match`。
- 版本冲突时保留草稿，不自动重试写入。用户主动选择“载入最新信息”后，才使用最新值替换草稿。
- 表单提交期间禁用重复操作，错误时保留输入。列表区分加载、数据、空结果、失败和刷新失败时的旧结果。
- 弹窗使用原生 `dialog` 处理焦点约束，支持 Escape 取消与关闭后焦点恢复。操作菜单可使用方向键和 Escape。
- 所有用户内容通过 React 文本渲染，不将用户输入注入 HTML。
- 日期显示为北京时间。窄屏使用横向导航和容器内表格滚动，避免整页横向溢出。

## 验证

```bash
npm run typecheck
npm run format:check
npx playwright install chromium
npm run test:e2e
```

Playwright 使用真实 FastAPI 和临时 SQLite。测试数据只存在于临时数据库中，服务退出后自动清理；浏览器错误追踪和截图保存在忽略提交的 `test-results/`。

## 代码职责

| 文件 | 职责 |
| --- | --- |
| `src/api.ts` | 请求封装、响应运行时校验、错误处理、版本头与类型 |
| `src/useSession.ts` | 会话恢复、登录、权限变化与失效处理 |
| `src/App.tsx` | Console 布局、导航、账号入口与页面权限 |
| `src/UsersPage.tsx` | 用户列表、统计、筛选和分页 |
| `src/UserDialog.tsx` | 用户创建、编辑、角色、状态、密码重置与删除 |
| `src/AccountPages.tsx` | 登录、首次改密、角色说明和个人设置 |
| `src/components.tsx` | 表单、弹窗、菜单、提示和展示组件 |
| `src/styles.css` | 桌面、窄屏及减少动态效果的样式 |
| `tests/console.spec.ts` | 浏览器操作与界面验证 |
| `tests/serve.py` | 浏览器测试使用的临时后端，不用于实际部署 |
