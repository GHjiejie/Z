# 团队任务管理需求

## 背景

一个 10 人研发团队目前通过群消息分配工作，希望有一个简单的网页任务管理工具，避免遗漏和重复沟通。

## 目标用户

- 团队负责人：创建任务、指定负责人、查看整体进度。
- 团队成员：查看分配给自己的任务，并更新状态。

## 已明确的需求

1. 任务包含标题、描述、负责人、截止日期和状态。
2. 状态包括待处理、进行中、已完成；完成的任务允许重新打开。
3. 任务列表支持按负责人和状态筛选。
4. 超过截止日期且未完成的任务需要突出显示。
5. 更新失败时给出清晰提示，并保留用户已填写的内容。
6. 第一版不做移动端应用、附件上传和外部消息通知。

## 尚未确定

- 使用公司统一登录还是单独注册账号？
- 谁可以编辑、删除任务和更换负责人？
- 已完成任务是否允许修改截止日期？
- 多人同时编辑时如何处理冲突？
- 是否需要操作历史？
- 技术栈、现有接口、部署环境和上线日期尚未提供。
