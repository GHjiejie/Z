# CrewAI Agent 开发约定

用户已明确要求本目录使用独立 Python 环境；本目录是仓库统一根环境约定的例外。

- 使用本目录的 `pyproject.toml`、`uv.lock` 和 `.venv` 管理依赖。
- 在本目录执行 `uv add`、`uv sync` 和 `uv run`；不要将本项目加入父目录的 uv workspace。
- 调整本项目依赖时，不修改仓库根目录的依赖或虚拟环境。
- 模型接入使用本环境可用的 CrewAI API，配置放在本目录 `.env` 中，避免导入依赖根环境的模型实例。
- 不提交 `.venv`、`.env`、密钥或运行时产物。
- 其余代码风格、验证和交付约定遵循仓库说明。
